About PlantVision

PlantVision is an AI-based plant disease detection system that analyzes leaf images and predicts plant health conditions.

How It Works

1. User uploads a plant leaf image.

2. The image is resized to 224 × 224 pixels.

3. MobileNetV2 processes the image.

4. The trained classifier predicts one of 38 supported classes.

5. PlantVision displays the plant, condition and confidence score.

6. The result is stored in SQLite for dashboard analysis.

Technologies Used

Python • TensorFlow • MobileNetV2 • Transfer Learning • Flask • SQLite • HTML • CSS • NumPy • Pillow

Model Performance

The current model achieved approximately 94.42% validation accuracy on the validation dataset.

The model supports 38 classes from the selected plant-disease image dataset.

Important Limitation

PlantVision is an educational AI system. Predictions are limited to the classes represented in its training dataset. Real-world photographs may differ from training images, so predictions should not be treated as professional agricultural diagnosis.
